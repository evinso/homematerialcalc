## How much tile to buy

| Room area | Standard size | Tiles needed (10% waste) |
|-----------|--------------|--------------------------|
| 50 sq ft | 12×12 in | 55 tiles |
| 100 sq ft | 12×12 in | 110 tiles |
| 100 sq ft | 12×24 in | 55 tiles |
| 150 sq ft | 12×12 in | 165 tiles |
| 200 sq ft | 18×18 in | 100 tiles |

Add 15% waste for diagonal patterns. Use the [Tile Calculator](/calculator/tile) for exact counts.

## What you'll need

**Materials:**
- Cement board (1/4" for floors; 1/2" for walls)
- Modified thinset mortar
- Tile (see calculator for count)
- Tile spacers (1/8" for most floors; 1/16" for large-format tile)
- Sanded or unsanded grout
- Grout sealer

**Tools:**
- Wet tile saw (rental)
- Notched trowel (3/8" V-notch for most tiles; 1/2" U-notch for large tiles)
- Rubber grout float
- Tile leveling clips (optional but great for large-format tile)
- Level and straightedge
- Rubber mallet

## Grout joint size guide

| Joint size | Best for | Grout type |
|-----------|---------|-----------|
| 1/16 inch | Rectified tile (precision edges) | Unsanded |
| 1/8 inch | Most floor and wall tile | Unsanded |
| 3/16 inch | Standard spacing | Sanded |
| 1/4 inch | Rustic, handmade tile | Sanded |
| 1/2 inch | Brick pattern, large format | Sanded |

## Thinset coverage by trowel size

| Notch size | Coverage per gallon | Tile size |
|-----------|--------------------|---------:|
| 3/16" V-notch | 50–60 sq ft | Up to 8×8 |
| 1/4" square | 40–50 sq ft | 8×12, 12×12 |
| 3/8" square | 30–40 sq ft | 12×12, 12×24 |
| 1/2" square | 20–30 sq ft | 18×18, large format |

Large-format tile (18×18 and bigger) also requires back-buttering — apply thinset to both the substrate AND the back of the tile for full coverage.
