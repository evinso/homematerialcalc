## Multiple beds: add them together

If you have several beds, measure each one separately and add the totals. Use the [Mulch Calculator](/calculator/mulch) with the Irregular shape option to enter all beds at once.

**Example:** Three beds — 4×8 + 4×12 + 6×8 = 32 + 48 + 48 = 128 sq ft total. At 3 inches, you need about 1.25 cubic yards (18 bags).

## Depth guide for garden beds

| Situation | Depth |
|-----------|-------|
| Annual refresh (existing mulch present) | 1–2 inches |
| New bed, standard | 2–3 inches |
| Heavy weed suppression | 3–4 inches |
| Around trees / shrubs | 3–4 inches (keep away from trunk) |
